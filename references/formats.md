## 1. Карусель / пост 4:5 — `Deck("carousel")`

Довжина 5–8 слайдів. Коротка: обкладинка → 3 пункти → заклик. Повна: обкладинка → ситуація → 3 пункти → підсумок → заклик. Лічильник і `@mari.ivanuk` ставляться самі.

**Обкладинка (слайд 1)** — гачок + фото Маші. Приклади: _(лише в приватній версії)_, `examples/pilot-carousel-01.jpg`.
```python
d.add(wrap(head("Мій AI прочитав [сотні переписок] клієнта"),
           sub("і знайшов, **куди зникали заявки**"),
           glass("реклама працювала"), glass("заявок купа"), pill("записів одиниці"), top=130),
      photo=bleed("/path/to/photo-at-desk.jpg", "right:0; bottom:0; height:1010px"),
      extra=corner_pill("гортай карусель, покажу 3 помилки)"))
```
Темне фото в червоному світлі — `bleed` (тане в тлі, вирізати не треба). Фото зі світлим тлом — спершу `scripts/cutout.swift`, потім `cutout(...)`.

**Слайд-пункт** — eyebrow + заголовок + текст + пігулки + 3D-предмет у порожньому низу:
```python
d.add(wrap(eyebrow("помилка №2"), head("[«Коли вам] зручно?»"),
           wrong("«коли вам зручно?»"), pill("«завтра о 17:00 чи в неділю об 11:00?»"),
           sub("Два конкретні часи на вибір, і людина **записується в рази частіше**.")),
      obj=prop(f"{L}/props/phone-chat.png", "right:90px; bottom:24px; height:500px; transform:rotate(8deg)"))
```

**Список «Що на тебе чекає»** — `numbered([...])`, 4–6 пунктів по одному рядку-двох. Приклад: _(лише в приватній версії)_.

**Підсумок** — `card("А головне тут:", [3 пункти])` + `cta("збережи, щоб не загубити")` + предмет.

**Заклик (останній)** — фото + заголовок-питання + текст + червона пігулка з кодовим словом + контурна кнопка:
```python
d.add(wrap(head("Хочеш навчитися [такого?]", 80), sub("5 днів безкоштовної практики, щоб зрозуміти, чи **таргет** це твоє"),
           pill("пиши «ТЕСТ» у Direct", 38), cta("надішлю доступ", 32), right=420),
      photo=bleed("/path/to/photo-from-back.jpg", "right:0; bottom:0; height:1350px"))
```
Варіант Ярослави: `banner(...)` з лівого краю + `label("бонус:")` + фото праворуч (_(лише в приватній версії)_). Ще варіант: `stats` + `circle_photo` + `bar` знизу (_(лише в приватній версії)_).

**Тези / «думки»** — `eyebrow("думка №3")` + `quote_head("без блогу ніхто не прийде")` + коротка історія + пігулка-висновок + мокап телефона чи скрін (_(лише в приватній версії)_).

## 2. Кейс

Обкладинка кейсу в сітці: зверху «КЕЙС:» червоним + ніша білим, 2–4 цифри в пігулках, кнопка «→ Дивіться кейс детальніше», фото Маші або предмет-метафора ніші.
```python
d = Deck("post")
d.add(wrap(head("[Кейс:] б'юті-салон у <місто>", 76),
           glass("бюджет X zł"), glass("N платних клієнтів за M днів"), pill("X zł → Y zł"),
           cta("Дивіться кейс детальніше", 32)), photo=cutout("/path/to/cutout.png"))
```
**Цифри кейсу — тільки ті, на які клієнт дав згоду.** Без згоди — описово, без назви клієнта.

## 3. Сторіс — `Deck("story")`

Сторіс у Ярослави спокійніші за каруселі: заголовки менші (56–70 px), по центру, багато повітря, скріни як докази. Верхні ~250 px і нижні ~300 px не займай.
- **Тези з поясненням** (_(лише в приватній версії)_): кілька блоків «ЗАГОЛОВОК —» + червона пігулка-пояснення під ним, тло `dark`, внизу смішний 3D-стікер (кіт в окулярах з грошима тощо).
- **Скріни** (_(лише в приватній версії)_): тло `grey`, текст угорі по центру + червона пігулка, нижче `shots([...])`.
- **Відгук** (_(лише в приватній версії)_): заголовок «НАВІТЬ ПЕРШИЙ [ВІДГУК] НАПИСАЛИ:», скрін у білій картці, під ним коротка реакція Маші.
- **«Вибух» заявок** (_(лише в приватній версії)_): `bg="red"`, `fire()`, білий капс, скріни заявок колонками.
- **Фото-сторіс** (_(лише в приватній версії)_): фото на весь кадр (`full`), заголовок угорі, червона пігулка внизу.
- **Мокап ноутбука/телефона з лендингом** (_(лише в приватній версії)_) — для анонсу сторінки чи курсу.

Сторіс-відео з Машею в кадрі — це моушн, див. `motion.md`.

## 4. Обкладинка рілс — `Deck("cover")`

1080×1920, але сітка профілю показує тільки середину 3:4 (y 240–1680). Стиль обкладинок Ярослави: мала червона пігулка + великий білий капс + ще одна пігулка; або тонкий світлий текст по центру.
```python
d = Deck("cover")
d.add(wrap(pill("мій AI прочитав", 44), bigcaps("сотні\nпереписок"), pill("і знайшов, де губляться заявки"), top=1150),
      photo=full("/path/to/portrait.jpg", "left:-64px; top:0; width:1208px; height:1920px; object-fit:cover", shade_from=960),
      bg="dark")
```
Три перевірені варіанти (`examples/pilot-cover-A/B/C.jpg`):
- **A** — кадр з самого відео, вирізаний `cutout.swift`, + 3D-предмет збоку;
- **B** — вирізане фото з фотосесії + предмет;
- **C** — портрет на весь кадр, текст на темному піджаку. Найсильніший.
